About This Project

This is a fun Python web application that roasts people by name! 🔥

How It Works

  1. User enters their name on the home page
  2. Python Flask processes the form submission
  3. The app displays a "roast" message with their name
  4. It's all in good fun! 😄

Technologies Used

  • Flask - Python web framework for handling routes and forms
  • Bootstrap - CSS framework for responsive design
  • HTML/CSS/JavaScript - Frontend technologies

Features

  • Interactive name input form
  • Dynamic message generation with user's name
  • Responsive design that works on all devices
  • Easy to share with friends for laughs
  • Animated skull emoji for extra effect

How to Share

To share this roasting website with your friends:

  1. Deploy to a hosting service like Railway, Heroku, or PythonAnywhere
  2. Share the URL with your friends
  3. Watch them get roasted! 😂
  4. They can access it from any device with a web browser
Disclaimer: This is just for fun! The "roast" is meant to be humorous and not offensive. Use responsibly! 🤗
